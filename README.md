# Ranker

A lightweight, single-file tier list application built with HTML, CSS, and JavaScript.

## Features

- Create and manage unlimited tier list boards.
- Customize tier names, colors, and order.
- Add items using images, URLs, or pasted lists of names.
- Bulk image uploads and automatic WebP conversion.
- Drag and drop items on desktop and mobile.
- Undo and redo changes.
- Import and export boards.
- Automatic and manual saving.
- Light and dark themes.
- Synchronize boards and images across devices using a private GitHub repository.

## Hosting

Ranker is hosted using GitHub Pages.

The application source code is maintained in this public repository.

## Setup

Open the hosted application to create and manage your tier lists. Create a board, customize its tiers, and start adding items.

The interface supports both desktop and mobile devices.

## Data and Privacy

Board data and uploaded images are stored privately.
